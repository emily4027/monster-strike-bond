# 怪物彈珠羈絆場次工具

線上版：https://emily4027.github.io/monster-strike-bond/

管理自己每個遊戲帳號的羈絆隊友（最多 3 位），依等級差估算跑滿羈絆條要打幾場，記錄達成次數、下一次獎勵，以及距離下一張寶珠交換券還差幾天。

## 功能

- **隊友名單**：其他玩家建立一次（名稱、社群帳號、等級），自己的帳號自動列入。名單上看得到每位隊友和哪些帳號羈絆中、今天羈完了沒。
- **多個帳號**：每個帳號有自己的等級，從名單選最多 3 位隊友。結束後再選回同一位會接續之前的次數。
- **場數估算**：等級差 → 需要體力（查表）→ 除以每場體力（預設 60，可每段個別設定）→ 跑滿要幾場。
- **＋1 場**：打完一場就按一下，到上限自動算達成一次，並顯示這次的獎勵。
  - 估少了：按「還沒滿」撤銷這次，上限 +1。
  - 估多了：按「已經滿了」立刻達成，上限改成目前場數。
  - 之後都照修正後的場數；等級差跨到另一格或每場體力改變時，改回重新估算。
- **打完一場…**：一場同時有多位隊友時，一次幫勾選的羈絆各 +1 場。
- **達成次數**：每段羈絆各自計算，20 次一輪；每段一天只能達成一次。
- **寶珠券倒數**：還差幾天（今天還沒達成時含今天）。
- **歷史紀錄**：結束的羈絆保留完整進度，之後可以找回接續。
- **雲端同步**：登入 Google 後存到 Firebase（和工具箱、其他工具共用登入）；未登入時存在瀏覽器。多台裝置同時修改時，以帳號 / 羈絆為單位自動合併。
- **備份**：下載 / 載入 JSON。

## 規則

- 「今天」一律以**台灣時間 00:00** 換日，不看裝置時區。
- 羈絆條換日不歸零；漏掉一天次數不中斷。
- 體力表與獎勵表在 `bond.js` 開頭的 `STAMINA_TABLE`、`REWARDS`，要修正數字只改這裡。

## 隱私

隊友的遊戲名稱與社群帳號是別人的資料，只存在你自己的瀏覽器或你自己的雲端私人路徑（`artifacts/{appId}/users/{uid}/bond_data/bond_tracker`，只有本人可讀寫），沒有任何分享功能。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 頁面與 Firebase 設定 |
| `style.css` | 樣式 |
| `bond.js` | 計算、資料整理、三方合併（純函式，不碰 DOM） |
| `script.js` | 畫面、存檔、雲端同步 |
| `tests/` | `node --test tests/` 執行，不需要安裝套件 |

## 本機開發

```bash
jwebserver -p 8000
```

在專案資料夾執行後開 `http://localhost:8000`（Firebase 登入要用 `localhost`，不要用 `127.0.0.1`）。

```bash
node --test tests/
```
