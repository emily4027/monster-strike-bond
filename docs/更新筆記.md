# 更新筆記

給管理者看的白話說明：每次新增或修改功能時，記錄為什麼改、現在怎麼運作、怎麼用。最新的在最上面。

## 2026-11-14：帳號區塊精簡，記錄場數統一在「今天一起打」

### 起因
「今天一起打」已經能記錄每一場，帳號區塊裡的「＋1 場」和「打完一場…」變成重複的功能；「今天已羈完」羈完的人多了會拉得很長。

### 現在的規則
- **記錄場數只有一個地方**：「今天一起打」的「打完這場」。只跟一個人打也一樣：上面只選那一個遊戲帳號就好。
- 帳號區塊變成**看細節和修正**的地方：
  - 卡片上的「＋1 場」拿掉了；保留「−1 場（記錯了）」和「已經滿了」。
  - 帳號最上面的「打完一場…」按鈕和視窗拿掉了，改成一行提示「打完一場到上面「今天一起打」記錄」。
  - 「修改次數 / 設定」、下一次獎勵、寶珠券倒數、結束羈絆、歷史紀錄都照舊。
- 「今天已羈完（N）」**預設收起來**，點開才看每一位拿到的獎勵和「還沒滿？放回隊伍」。

### 拿掉之後的影響
- 原本「打完一場…」視窗裡「同一場的自己帳號之間也 +1」的功能一起拿掉（你說過自己帳號之間一定會滿，不用計算）。

## 2026-11-14：「今天一起打」帶哪些帳號更好辨識

### 起因
排程只用文字寫「羽入 + 梨花 打 1 場」，一眼看不出這場要帶誰。

### 現在的樣子
- 自己的每個帳號有一個**固定顏色**（照帳號順序），下面的帳號分頁名稱前面也有同色的小圓點，兩邊對得起來。
- 排程最上面有醒目的「**下一場帶**」框，用彩色標籤顯示這場要帶的帳號，下面寫「這個組合還要打 N 場」。
- 「全部排程」每一步也用彩色標籤，同樣組合合併成一步（例如「羽入 + 梨花 × 2 場」），目前這一步標「現在」。
- 「這一場實際帶了誰？」預設照「下一場帶」；你改過的話標題會提醒「和建議不同」。
- 原本「要羈絆的自己帳號」改叫「參加排程的自己帳號」，跟「這一場實際帶了誰」分清楚。

## 2026-11-14：其他玩家改成「社群帳號 + 多個遊戲帳號」、新增「今天一起打」

### 起因
1. 其他玩家也跟你一樣不只一個遊戲帳號，原本一位玩家只能填一個遊戲名稱和等級。
2. 選好今天的羈絆對象後，想讓程式算出「該帶自己哪兩個帳號」最省場數。
3. 原本用 A、B 兩個帳號配別人的 Z、X 打一場，要在 A、B 各選一次 Z、X，打完也要在 A、B 各按一次 +1。

### 現在的規則
- **其他玩家 = 一個社群帳號**（平台 + 帳號名稱），底下可以有好幾個**遊戲帳號**（名稱、等級各自填）。
  - 羈絆算在「我的帳號 × 他的某個遊戲帳號」，每組各算各的次數和場數。
  - 平台和帳號名稱都一樣的，就是同一位玩家，不能重複新增（會提示你去那位玩家的「編輯」加遊戲帳號）。
  - 舊資料自動轉換：原本每位玩家變成「一位玩家 + 一個遊戲帳號」，進度不變；社群帳號相同的舊玩家會合併成一位。
- **今天一起打**（隊友名單下面）：
  1. 點選這幾場要一起打的其他遊戲帳號（最多 3 個，因為一場最多 4 人，至少要留 1 個位子給自己）。
  2. 點選要一起羈絆的自己帳號（預設全部）。
  3. 表格列出每個自己帳號 × 每個遊戲帳號還差幾場；還不在隊伍的顯示「不在隊伍・約 N 場」。
  4. 程式排出最少場數：每場能帶 4 −（其他遊戲帳號數）個自己的帳號，每場優先帶「還差最多場」的帳號。總場數 = 「最多的那個帳號要打幾場」和「全部加起來 ÷ 每場能帶幾個（無條件進位）」兩者取大，這已經是最少。同樣組合合併成一步，例如「羽入 + 梨花 打 2 場」。
  5. 「這一場帶了誰？」預設照第一步建議，可以自己改；按「打完這場」，這場的「自己帳號 × 其他遊戲帳號」每一組各 +1 場，不用切換帳號一個一個按。
  6. 還不在隊伍的會自動加進隊伍（以前羈絆過的接續次數）；隊伍位子不夠（最多 3 位，自己帳號也佔位子）的帳號會標示「隊伍位子不夠」，不排進去。
  7. **自己帳號之間的羈絆不計算**（一起打一定會滿），也不會 +1；別人兩個遊戲帳號之間也不記錄。
  - 選了哪些人只記在這台瀏覽器上。

### 資料或畫面的變動
- 名單上「其他玩家」一位一列，標題是社群帳號名稱，下面一行列出所有遊戲帳號和等級；展開後每個遊戲帳號各自顯示和你各帳號的羈絆，各自有「調整進度」。
- 「新增 / 編輯玩家」視窗：先填社群帳號，再填一個或多個遊戲帳號（可新增、移除）。移除正在羈絆的遊戲帳號，羈絆會結束、次數留在歷史紀錄。
- 「從名單選隊友」列出的是每個遊戲帳號（🎮 名稱，後面附上是哪位玩家）。
- 排序「等級高到低」看玩家最高等級的遊戲帳號，「等級低到高」看最低等級的。

### 沒驗證的部分
- 已登入 Google 時，雲端上的舊格式資料轉換（用測試確認過合併不會重複，但沒有用真的雲端資料試）。
- 「打完這場」在手機上的實際操作（只用瀏覽器模擬手機畫面確認過版面）。

## 2026-11-14：隊友名單的排序、「全部展開／收合」修正

### 起因
- 其他玩家一多，只能照加入順序看，想依等級或「還沒羈絆的先看」來找人。
- 右上角的「全部展開／全部收合」：手動把每一列都收起來後，按鈕還是寫「全部收合」，要多按一次才會變成「全部展開」。

### 現在的規則
- **排序**：「其他玩家」標題右邊有下拉選單，可以選：
  - 加入順序（預設）
  - 未羈絆優先：還沒和任何帳號羈絆的玩家排前面，其餘照加入順序
  - 等級高到低／等級低到高
  - 名稱
  選擇只記在這台瀏覽器上，換裝置要重選。「自己的帳號」不受影響。
- **全部展開／收合**：按鈕文字永遠跟著「現在」的狀態：只要有任何一列是開著的就顯示「全部收合」，全部都收起來就顯示「全部展開」。手動點開或收起任一列，按鈕會馬上更新，按一次就有效。

### 沒驗證的部分
- 在手機上實際操作下拉選單（只用瀏覽器模擬確認過畫面）。
